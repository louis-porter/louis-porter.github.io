# XGBoost Match Prediction Study

This project (find here on [GitHub](https://github.com/louis-porter/football-analytics/tree/main/models/match-prediction-model)) is more of a research focused study using an XGBoost model to predict match outcomes using a poisson model after predicting the number of expected goals.

The accuracy of the model was then compared to Bet365 "fair" odds and was found to be more precise.
